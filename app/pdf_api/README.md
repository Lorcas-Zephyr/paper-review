# PDF 上传网关（pdf_api）

## 简介

接收前端上传的 **PDF 文件**，做基本校验（类型、大小等），保存到服务器约定目录，并返回可供后续转换服务使用的**文件路径或标识**。不执行耗时的全文解析，与 **pdf_to_md** 解耦。

## 在本系统中的位置

- **上游**：前端上传接口（经代理指向本服务，默认端口 **5000**）。
- **下游**：`pdf_to_md` 或其它转换服务根据返回路径读取文件并生成 Markdown。
- **不涉及**：LLM、论文评阅数据库；无 Token 消耗。

## 工作流程

1. 接收 multipart 上传。
2. 校验魔数、扩展名与大小上限。
3. 写入磁盘（如 `uploads/`），返回 JSON（含 `file_path` 等字段，以实际 API 为准）。
4. 前端或编排脚本再调用 **8002** 等端点触发转换。

## 启动

```bash
pip install -r requirements.txt
python main.py
```

默认 `http://0.0.0.0:5000`。
