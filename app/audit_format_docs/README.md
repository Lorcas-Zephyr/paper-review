# 格式审计扩展文档（audit_format_docs）

## 简介

本目录为 **`audit_format` 格式审计智能体**的配套说明与设计资料，与可运行的代码目录 `../audit_format` 分离：存放指标体系、开发规范、测试说明等**文本文档**，不单独启动服务。

## 与主流程的关系

- **评阅主干**：用户仍通过前端 → 调度器 → `audit_format` 服务完成格式审计；本目录不参与运行时加载。
- **内容作用**：为规则设计、坐标高亮方案、与数据库规则表映射等提供依据；新增或修改规则时可同步更新此处文档与 `audit_format/rules.yaml` / 库表。

## 文档索引（按需阅读）

- `软件工程硕士研究生学位论文质量评价指标.md`：学科向宏观指标与等级描述。
- `格式审计_开发规范.md`：接口与工程约定。
- `测试说明.md`：格式组侧测试与回归方式。

服务启动、环境变量与端口请始终以 **`../audit_format/README.md`** 为准。
